# Student Submission Branch

This branch prepares the project for university portfolio submission.

The core Knowledge Graph work remains unchanged:

- curated funding-event CSV data;
- validation and normalization scripts;
- Neo4j import CSVs;
- Cypher schema, validation, analysis, and visualization queries;
- React graph explorer for screenshots and demonstration.

The student-facing React UI is limited to academic exploration:

- graph, analytics, news, and methodology/legal views only;
- full graph exploration without feature gating;
- legal text reframed as an academic demonstrator.

Use the web app only as an optional graph exploration layer in the portfolio.
The main assessed work should remain the data curation, Neo4j graph model,
Cypher analysis, and portfolio report.

Recommended screenshots:

- Neo4j Browser validation counts;
- Neo4j Browser analysis tables;
- Neo4j Browser graph visualizations;
- one or two React graph explorer screenshots.
