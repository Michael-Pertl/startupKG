# Hackathon demo checklist

- Install dependencies with `npm ci` in `web/`.
- Set a server-side `NEBIUS_API_KEY` and run `npm run check:deploy-env`.
- Run `npm test` and `npm run build`.
- Start `npm start` and check graph selection, context lenses, analytics, news source links, and Ask.
- Keep `.env` files and real keys out of the submission.
- Record a short demo using the sequence in [HACKATHON_SUBMISSION.md](HACKATHON_SUBMISSION.md).
- Check the chosen hackathon's eligibility, required artifacts, deadline, and submission form before submitting.

The graph represents curated publicly reported AI mega-rounds above the selected funding threshold, not the full AI startup ecosystem.
